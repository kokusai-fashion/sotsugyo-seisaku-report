# 設計：先生の許可の仕組み（点検表）

2026-11-04 に依頼者と1つずつ決めた内容と、その作り方。見本は mockups/v101〜v108。
11/12 の学生への配信の前に出す（依頼者 2026-11-04）。

## 決めたこと（依頼者の選択）

- **コースごとの切り替え**（管理ページの「コースごとの設定」の欄「先生の許可」。v103）
  - 「抄録は、先生の許可が出てから書ける」「提出用の PDF は、先生の許可が出てから作れる」の2つ。はじめは両方とも切ってある（今のまま）。
  - そのコースの**先生も**切り替えられる（管理者だけではない）。
  - 切ってあるコースは今のまま：抄録は学生が自分で「先生の許可が出た」を押す。PDF に「点検用」の印は入らない。
- **点検表**：ツールがコースごとに作る Google スプレッドシート。2026-11-09 から、管理ページの「点検表」の画面でも見て書ける（下の「点検表の画面」。中身はスプレッドシートのまま）。
  - 学生には配らない。学生は、ツールの中で**自分の行だけ**を見る（右の欄・スマホはメニューの「点検の予定と記録」。v105）。
  - 2段組。**25人まで1段、26人からは半分ずつ2段**（人数が 25 をこえたら組み直す。先生の書いた中身は学生と一緒に動く）。
    コースで「いつも縦1列」も選べる（2026-11-09 依頼者。管理ページの「点検表の並び」の「並べ方」。v119）。
  - 学籍番号・ふりがなは表に出さない（行を見つける印は見えない所に）。ふりがなは並べる順にだけ使う。
  - 列：番号・（所属：所属を登録したコースだけ）・氏名・最新 PDF（日付。押すとその PDF）・回の列（1回目・2回目・3回目・4回目・抄録。白い列）・抄録許可・最終提出可（✓。うすい黄色）・教務提出（✓）・知らせ。
    （2026-11-07 依頼者：回の列は「4回目・抄録」の順に。見出しは役目ごとの淡い色と濃い字（ツールが書く列は灰色 #dadce0・回の列は青 #d6e4f5・許可は黄色 #f8dc8c・教務提出は緑 #d3ead6）。氏名の列も灰色。長い氏名は折り返す）
  - 回の列（白い列）はコースで自由（足す・消す・名前を変える）。ツールが決めておくのは、灰色の列と、許可の2列だけ。
  - 回の列は、そのコースの指導教員の名字のプルダウン：「山本 予定」（灰色の字）→ 見終わったら「山本 済み」（先生ごとのくすんだ淡い色。v107 案A。1人目は 2026-11-07 から薄赤 #f8e1e4/#8a3442（前の青 #e6edf5/#30527a は、回の列の見出しの薄青と似ていた）・緑 #e7efe6/#3d6342・砂 #f2ece0/#7a5a2c、4人目からは繰り返し）。
  - 先生の名前は、管理ページの「指導教員」の欄から（名字。区切りは「、」）。
  - 並び：コースで選ぶ（2026-11-09 依頼者。管理ページの区切り「点検表」の「点検表の並び」の「順番」。v119・v120 案C）。五十音順（ふりがな（セイ・メイ）のあいうえお順。はじめ）か学籍番号順。
    先生が管理ページで並べ替えられる（「点検表の並び」の欄の「学生の並びを直す」→ 窓。⋮⋮ と ▲▼。「手で動かした」の印。「五十音順に戻す」「学籍番号順に戻す」。v103 案1）。
    順番を変えたら、前に手で直した並びは使わない（直したときの順番をスクリプト プロパティ orderMode:年度:コース に覚える）。
  - **所属**（制作グループなど。2026-11-09 依頼者。v118・v119・v120 案C）：先生（管理者もそのコースの先生も）が、コースの欄の「所属」に名前を登録する（名前の札。20個・30字まで、同じ名前は1つ）。
    - 学生は、はじめての案内で**氏名のあと**に「所属を選んでください」（選ぶまで閉じられない）。所属を選んでいない原稿を開いたとき（先生があとから登録した・名前を変えた）・所属のあるコースに変えたときも、所属だけを聞く。表紙のコース欄の「コースを選ぶ」の下でも選び直せる。コースを変えたら所属は消す。先生のお試しでは開いたときに聞かない。
    - 点検表は所属ごと（登録した順。選んでいない学生は後ろ）に並び、その中は「順番」。番号の右に「所属」の列（ツールが書く列。所属ごとに淡い地と濃い字で色分け：登録した順に青灰・藤色・水色、4つ目からは繰り返し。選んでいない学生は灰色。v121 案A）、所属の境の上に太い線。2列のときは、今と同じく人数の半分で分ける（所属が左右に分かれることがある）。所属を全部消すと、所属の列もなくなる。
    - 学生が間違えて選んだら、学生が表紙のコース欄から直すか、**先生が**「学生の並びを直す」の窓の「所属」の欄で直す（2026-11-09 依頼者：先生も直せる）。窓の中で動かせるのは所属の中だけ。
    - 学生も先生も直せるので、所属には**決めた日時**を持たせ、新しい方を使う：名簿の「所属の日時」より古い所属が学生のツールから届いても（先生が直す前の別の端末など）書かない。学生のツールは checkStatus の答えの所属が原稿の所属より新しければ受け取り、「先生が、所属を「〜」に直しました」と知らせる。
- **抄録**（許可を使うコース。v108 ①）：学生の「先生の許可が出た」ボタンはなくし、「先生の許可を待っています」＋「許可が出たか、確かめ直す」。許可が出たら「先生の許可が出ました（12/15　小川先生）」＋「抄録を書き始める」（学生が押して書き始める）。
- **最終提出**（許可を使うコース。v102 案B・v108 ②）
  - 許可の前の PDF：全ページの右上の余白に赤い枠の「点検用」（約10pt・太字・枠 1.2pt・白地。上から 22pt・右から 28pt。字間を入れるので、左の内側の余白 = 右の内側の余白 + 字間）。ファイル名は「〜_点検用.pdf」。PDF の窓に赤い知らせ。
  - 許可のあと：印のない提出用 PDF。PDF の窓に緑の「最終提出の許可が出ています（日付・先生）」。
  - 許可のあとに書き換えた：許可は残す。PDF の窓に一言、点検表の「知らせ」に「書き換え 1/14」（赤）。
- **氏名**：姓・名・セイ・メイの4つの欄（v101。作った：2026-11-04）。ふりがなは表紙に出さない。
- **点検表の画面**（2026-11-09 依頼者。見本 mockups/v122〜v126、選んだのは v126（最初の見本 v122 の見た目））：管理ページの左の見出しのいちばん上「点検表」。
  - 見せ方は「表」「カード」「担当の目線」（この端末で覚える。はじめはパソコンが表、スマホが担当の目線）。範囲（自分の担当・コース全体。はじめは割り振りがあれば自分の担当）と所属で絞る。回の札を押すと「済み」⇄「予定」、許可はスイッチ。「担当の目線」の「まだの分」は、始まった回（だれか1人でも済み）で残っている自分の担当。
  - 直接入るリンク：管理ページの URL に ?view=check（管理者は &course=コースの ID も）。ブックマークやスマホのホーム画面に置く（「この画面のリンク」）。
  - **担当の割り振り**：所属（または等分した班）×回の表で先生を選ぶ。「1回ずつずらして埋める」（1回目に1つ目の所属の先生は、2回目は2つ目へ）。「点検表に入れる」で回の欄に「名字 予定」（「済み」と空の割り振りの欄は書き換えない）。割り振りはスクリプト プロパティ assign:年度:コース に覚え、10分ごとの写しで、あとから来た学生・まとまりが変わった学生にも入れる（入れたときのまとまりを assignGroups:年度:コース に覚える）。
  - **並び順で等分**（所属を使わないコース）：コースの欄の「所属」で「並び順で等分」（2〜6。checkSplit）。学生には聞かず、点検表の並びを上から等分して「1班」「2班」…（割り切れなければ前の班から1人ずつ多く）。人数が変わったら**いつも分け直す**（依頼者の選択）。所属の列に班を書く。
- **氏名と担当コース**（2026-11-09 依頼者）：先生は、はじめて管理ページを開いたときに氏名と担当コースを登録する（閉じられない窓。指導教員の一覧から名前を押す。担当のコースは**1つだけ**：依頼者「複数選択できると逆に間違っても困る」）。先生は担当のコースだけを見る・直す（コースごとの設定はそのコースを開いたまま。点検表もそのコース）。管理者は全部。

## 作り方

### 学生の名簿（学科の管理用スプレッドシートの新しいシート「学生の名簿」）

点検表のもとになる一覧。学生のツールが書き込み（API）、管理ページの仕掛けが点検表に写す。

| 列 | 中身 |
|---|---|
| 年度 | 2026 |
| コース | courseId |
| 学籍番号 | 行を見つける鍵（年度・学籍番号で1行） |
| 姓・名・セイ・メイ | 学生が入れたもの |
| 並び | 先生が並べ替えた順（空ならコースの順番：五十音順・学籍番号順） |
| PDF の ID・PDF の日時 | 最後に送った PDF の控え（pdfCopy） |
| 書き換え日時 | 最終提出可のあとに書き換えた最後の日時（学生のツールが知らせる） |
| 更新日時 | |
| 所属・所属の日時 | 学生が選んだ・先生が直した所属と、決めた日時（ISO。2026-11-09 から。前の名簿にはないので、いちばん右に足した） |

（許可の状態は、名簿ではなく点検表のほうが正。学生への答えは点検表を読む）

### 学生のツール → API（gas/api-project。今の権限のまま。新しい権限は足さない）

doPost に足す action（どれも pdfCopy と同じログインの確かめ。学籍番号はアカウントと同じであること）：

- `register` { token, year, courseId, studentId, familyName, givenName, familyKana, givenKana, group, groupAt }
  学生の名簿に入れる・直す（コース・氏名・所属が変わったら直す）。ツールは、コースと氏名の4つの欄がそろったとき・変わったときに送る。
  所属は、コースに登録してある名前だけ（ほかは ''）。名簿の所属の日時より新しいとき（またはコースを変えたとき）だけ書く。前の版のツール（group を送らない）は所属を変えない。
- `checkStatus` { token, year, studentId } →
  `{ ok, enabled: { abstract, final }, row: { rounds: [{ label, teacher, state: 'done' | 'plan' | '' }], abstractOk: { at, by } | null, finalOk: { at, by } | null } | null, group, groupAt }`
  （group・groupAt：名簿の所属と決めた日時。先生が直した所属を学生のツールが受け取る）
  コースの切り替えは年度設定から。row は点検表の自分の行（なければ null）。
- `touchAfterFinal` { token, year, studentId, at }：最終提出可のあとに原稿を書き換えた（ツールは1日1回まで送る）。名簿の「書き換え日時」に入れ、点検表の「知らせ」に出す。
- 今の `pdfCopy`：名簿の PDF の ID・日時も書く（行がなければ作る）。

点検表は管理側の仕掛けが作る。まだなければ checkStatus の row は null（許可もまだ）。

### 管理ページ（gas/admin-project）

- 年度設定のコースに `permission?: { abstract?: boolean; final?: boolean }`。先生も保存できる（saveTeacherEdits に足す）。
- `ensureCheckSheet(year, courseId)`：コースの点検表を作る（なければ）。置き場所は、PDF の控えの年度のフォルダ（「2026年度」）の中のコースのフォルダ（見られる人は PDF の控えと同じ）。作ったら ID を年度設定の外（シート「点検表」：年度・コース・ID）に覚える。URL を返す（「点検表を開く」）。
- 年度設定のコースに `groups?: string[]`（所属）・`checkById?: boolean`（学籍番号順）・`checkOneColumn?: boolean`（いつも縦1列）。先生も保存できる（saveTeacherEdits の sheets）。
- `listStudents(year, courseId)` / `saveStudentOrder(year, courseId, studentIds | null, groups)`：並べ替えの窓（null は決まった順に戻す。groups は先生が直した学生の所属：学籍番号 → 所属。名簿の所属と所属の日時（今）を書く）。
- 仕掛け（10分ごと。届いた声のメールと同じ仕掛けに足す）：名簿 → 点検表（新しい学生を足す・氏名と PDF の日付を直す・1段／2段を組み直す・知らせを書く）。
- 先生が ✓ を入れた時刻と人：点検表の編集の仕掛け（installable onEdit。作るときに付ける）で、見えない列に「日時・先生の名字」を残す（アドレス → 先生の登録の氏名・メモ → 指導教員の名字）。
- 点検表の画面：getCheckView(year, courseId)（回・学生ごとの回の欄・許可・まとまり・割り振り）、setCheckCell(year, courseId, studentId, field)（回の欄か ✓ を1つ書く。✓ は記録の列も。DocumentLock）、saveAssignment(year, courseId, assignment)（割り振りを覚えて点検表に入れる）。
- 氏名と担当コース：「管理者」シートの4・5列目（氏名・担当コース）。setMyProfile(name, courseId)（自分）・setMemberProfile(email, name, courseId)（管理者だけ）。getState の me に返す。先生は requireCourseAccess_（点検表の画面・並べ替え・点検表を作る）と requireOwnCourseEdits_（saveTeacherEdits）で、担当のコースだけ。担当コースをまだ登録していない先生は、今までどおり（登録の窓が先に出る）。

### 学生のツール（画面）

- 開いたとき・ログインしたとき・「確かめ直す」で checkStatus。答えはこの端末に覚えておく（つながらないときは前の答え）。
- 抄録のページ・PDF の窓・PDF の印とファイル名・右の欄（スマホはメニュー）の「点検の予定と記録」。
- 最終提出可のあとに原稿を変えたら touchAfterFinal（1日1回）。
