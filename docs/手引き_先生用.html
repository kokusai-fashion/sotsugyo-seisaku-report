01
HOW YOU GUIDE

指導のしかたは、これまでと同じ

  1. 1学生がツールで書く書式はツールが整える
  2. 2印刷して持ってくるPDF を印刷
  3. 3先生が赤を入れて返すこれまでどおり紙で
  4. 4学生が直す直したら、また 2 へ

先生がツールを操作する必要はありません。
PDF の控えは、先生のフォルダにも届きます（見たいときだけ）。

02
WHAT CHANGES

書式とルールの点検は、ツールが受け持ちます

  1. 1書式は崩れない
    決まった書式に書き込むので、学生は書式をいじれない

  2. 2ルールの誤りは、学生が直してから出す
    学科の執筆ルールに合わない所は、セルフチェックで学生が直す

先生は、内容が適しているかの指導に力を注げます

03
ADMIN PAGE

コースごとに、ひな形とお知らせを設定できます

  • URL は管理者からメールで届く
  • 学生の画面を試す
    見本の原稿で試せる
  1. 1

    ひな形を作る画面を開く
    最初の章立てと説明を書く

  2. 2

    お知らせを書く（締切など）
    個人の情報は書かない

  3. 3

    保存して学生に反映
    約1分で学生の画面に出る
